# Эталонная разметка

`golden.csv` — синтетическая разметка релевантности новостей из `data_synthetic/news` для трёх демо-компаний
(0 — нерелевантно, 1 — косвенно, 2 — прямо значимо). Разметку подготовил разработчик для проверки пайплайна;
перед защитой её заменяет независимая разметка двух бизнес-аналитиков на реальных новостях (раздел 9.1 ТЗ).

Запуск: `make eval` (или `uv run python -m app.eval`). Результат печатается и сохраняется в `eval/results.json`.
