# Безопасность AI-компонентов

| Риск | Механизм | Где |
| --- | --- | --- |
| Доступ к данным чужой компании | `company_id` и роль берутся только из подписанного токена; все запросы фильтруются по компании; чужой инсайт → 404 и запись в `audit_log` | `app/api/auth.py`, `routes.py::_own_insight` |
| Агент выходит за рамки | Белый список 9 инструментов, все только на чтение; аргументы `company_id`, `role`, `user` от модели отбрасываются; лимиты аргументов (`top_k ≤ 10`, `days ≤ 30`) и числа вызовов | `app/agent/tools.py` |
| Prompt injection из новостей | Предложения-инструкции вырезаются до классификации и извлечения фактов, событие помечается `prompt_injection_suspected`, факт пишется в аудит; системный промпт помечает материалы как данные; ответы моделей валидируются JSON-схемой | `app/processing/classify.py`, `app/llm/client.py` |
| Галлюцинации и искажение позиции банка | Утверждения `fact`/`bank` проверяются по первоисточнику (цитата и числа); неподтверждённые удаляются; при нехватке данных — `insufficient_data` | `app/agent/verifier.py` |
| SSRF при анализе по ссылке | Только http(s), запрет внутренних адресов (с проверкой после каждого редиректа), таймаут 10 с, лимит 2 МБ | `app/ingest/news.py::fetch_url` |
| Перерасход бюджета и злоупотребление | Учёт ₽ по каждому вызову, экономный режим при 95% лимита, кэш, rate limit: 20 анализов и 60 вопросов в час, 3 пересборки в час | `app/llm/client.py`, `app/api/auth.py` |
| Утечка чувствительных данных | В Git только синтетика; реальные данные — в `data/` (в `.gitignore`); ключи — в `.env` / секретах; в промпт идут признаки, а не сырые строки CSV; приватные новости пользователя не видны другим | `.gitignore`, `routes.py` |
| Непрозрачность решений | Полная трасса каждого запуска: план, вызовы, модели, токены, проверки, признаки | таблица `trace`, `/insights/{id}/trace` |

Для промышленной версии: SSO банка вместо тестовых учёток, ролевая модель доступа к админке, шифрование БД,
хранение ключей в vault, отдельная учётная запись LLM-шлюза с журналированием на стороне банка.
