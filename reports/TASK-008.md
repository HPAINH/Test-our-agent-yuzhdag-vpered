# TASK-008 — Изменения по ответам вебинара

**Результат.** Продукт приведён к ответам организаторов: данные чистятся по их пояснениям, доступ только для
действующих клиентов, у пользователя может быть несколько компаний, в инсайте разделены факты, позиция банка,
выводы модели и гипотезы, есть шкала влияния с определениями и дисклеймер, после инсайта можно обратиться
к менеджеру или скрыть событие, профиль уточняется пользователем, новости обновляются сами. Соответствие всем
74 ответам — [docs/webinar-qa.md](../docs/webinar-qa.md).

**Изменённые области.** `app/profile/{loader,builder,store}.py`, `app/ranking/score.py`, `app/agent/{analyst,verifier,chat}.py`,
`app/api/{auth,launch,routes}.py`, `app/{schemas,config,main,monitoring,seed,synthetic,worker}.py`, `app/db/{models,session}.py`,
`app/ingest/news.py`, `config/interpretation.yaml`, `data_synthetic/*`, UI (лента, карточка, чат, профиль, качество, шапка),
`.devcontainer/devcontainer.json`, `docker-compose.yml`, документация. Новые таблицы: `user_company`, `hidden_event`,
`service_request`.

**Проверки (самопроверка, не независимое ревью).**

- `pytest` — 50 тестов пройдены, из них 10 новых в `tests/test_webinar.py`;
- `ruff check app tests` — без замечаний; `tsc --noEmit` и `npm run build` — без ошибок;
- `make eval` — без изменений: precision@5 = 1.0, nDCG@10 = 0.934, различие лент 0.75, проверка Verifier 100%;
- headless Chromium после `seed --reset`: у `cfo_a` три компании в шапке и переключение; скрытие и возврат события
  в ленте; в карточке — блок влияния, метки «Факт / Альфа-Банк / Вывод модели / Гипотеза», заявка на обратный звонок
  с номером, дисклеймер; отметка «Важно» в профиле; страница качества с продуктовыми метриками и источниками;
  демо-хост и чат из прошлых задач работают; ошибок JavaScript нет.

на странице «Качество сервиса»; live-режим моделей.

общие для всех пользователей компании; для применения новых синтетических данных нужен `python -m app.seed --reset`.
