# TASK-007 — Точка входа из интернет-банка Альфа-Бизнес

**Результат.** Интернет-банк открывает «Пульс бизнеса» без повторного входа по подписанной одноразовой
ссылке и показывает на главном экране виджет с главными событиями и счётчиком для кнопки в шапке.
Демо-хост `/host-demo.html` проходит сценарий от главного экрана банка до карточки инсайта.

**Изменённые файлы.** `app/api/launch.py` (новый), `app/api/routes.py`, `app/config.py`, `app/db/models.py`
(таблица `launch_nonce`), `app/main.py` (`frame-ancestors`), `app/schemas.py`, `ui/src/pages/Embed.tsx` (новый),
`ui/src/App.tsx`, `ui/src/api.ts`, `ui/src/router.ts`, `ui/src/pages/Login.tsx`, `ui/src/styles.css`,
`ui/public/host-demo.html` (новый), `tests/test_launch.py` (новый), `docs/integration.md` (новый),
`docs/openapi.json`, README, ARCHITECTURE, DECISIONS (D-011), TASKS, THIRD_PARTY_NOTICES, `.env.example`.

**Проверки (самопроверка, не независимое ревью).**

- `pytest` — 40 тестов пройдены, из них 6 новых: успешный вход, одноразовость, 6 видов отказа, белый список
  `target`, выключение демо-подписанта, запись в audit_log;
- `ruff check app tests` — без замечаний;
- `tsc --noEmit`, `npm run build` — без ошибок;
- headless Chromium: `/host-demo.html` → счётчик 6 на кнопке → виджет из 3 событий, высота iframe подстроилась →
  клик по событию открыл карточку инсайта под тем же пользователем → «Назад» вернул на главный экран банка,
  токена в истории нет → смена пользователя и кнопка в шапке открыли ленту CEO другой компании →
  испорченная ссылка показала ошибку на экране входа; ошибок JavaScript нет;
- чат на карточке (6 быстрых кнопок и свободный вопрос) работает как раньше;
- заголовок `Content-Security-Policy: frame-ancestors 'self'` на HTML проверен `curl`.

**Не проверено.** Встраивание с другого домена (нужен реальный адрес банка в `EMBED_ALLOWED_ORIGINS`);
Safari с блокировкой сторонних cookie (сервис cookie не использует, но не прогонялся).

**Ограничения.** Пользователи заведены заранее; одноразовость nonce — в БД сервиса; демо-подписант
включён по умолчанию (`HOST_DEMO=true`) и в продакшне выключается.
