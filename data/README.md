# Данные кейса

Учебные данные организаторов хакатона. Сервис берёт их отсюда автоматически, если в папке есть CSV.

| Файл | Что внутри |
| --- | --- |
| `df_Uid_data_hack.csv` | 85 525 юрлиц: ОКВЭД, тип клиента (CLIENT / PROSPECT / CLOSE_CLIENT), продукты банка, ВЭД, выручка за 2025 год, группа, город и регион обслуживания |
| `df_Fid_Uid_link_hack.csv` | 12 514 связей физлиц с компаниями (город и регион обслуживания) |
| `df_Uid_payment_hack.csv` | 1,38 млн пар «плательщик — получатель» с суммой и числом операций с 1 января |
| `alfa/*.pdf` | 9 отчётов Центра макроэкономического анализа Альфа-Банка |
| `alfa/reports.yaml` | Названия и даты отчётов для ссылок в инсайтах |
| `alfa/.ocr_cache/` | Результат OCR страниц отчётов (Tesseract), чтобы не распознавать заново при каждом запуске |
| `users.yaml` | Демо-учётки для трёх компаний-клиентов из выборки |

Очистка при загрузке (по ответам организаторов на вебинаре): выручка ≤ 1000 ₽ — заглушка, повторяющийся
технический идентификатор `U_428697` исключён, переводы между своими счетами (82% объёма платежей) не считаются
контрагентами, контрагенты вне таблицы юрлиц помечаются «нет в выборке», крупный бизнес — по выручке группы.
