# Реальные данные кейса

Эта папка не попадает в Git (кроме этого файла). Положите сюда материалы кейса:

- `df_Uid_data_hack.csv` — юридические лица;
- файл физлиц (`SYNTHETIC_F`, `SYNTHETIC_U`) и файл платежей (`PAYER`, `BENEFICIARY`, `PAY_AMT`, `PAY_CNT`) —
  загрузчик определяет их по колонкам, поэтому одинаковые имена файлов в кейсе не мешают;
- `users.yaml` — тестовые учётки для реальных компаний (формат как в `data_synthetic/users.yaml`);
- `alfa/` — PDF-отчёты Центра макроэкономических исследований;
- `news/*.jsonl` — снимок новостей (необязательно, если включён RSS).

Затем задайте в `.env`: `DATA_DIR=/srv/data`, `ALFA_DIR=/srv/data/alfa`, `NEWS_DIR=/srv/data/news`.
